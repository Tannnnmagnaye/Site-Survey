DOLE PLC PHASE 2 SURVEY - LOCAL APP
All entries are stored on the device that opens the app. Nothing is sent anywhere.

A) Simplest (any phone, no internet, no hosting)
 1. Copy index.html (and the icon files) to the phone.
 2. Android: open Files, tap index.html, choose Chrome.
 3. Location cannot be read automatically from a local file; use "Enter manually" in Menu > Manage sites.

B) Install as an app (automatic location + works offline afterwards)
 1. Put all files in this folder on any https address once (Netlify Drop or GitHub Pages).
 2. Open that address on the phone, then Add to Home Screen (iPhone) or Install app (Android).
 3. After the first visit it runs offline and stores data on the device.

Back up often: Menu > Export / restore. Clearing browser data erases entries.
